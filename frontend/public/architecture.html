⚡ Microsecond Vote Lifecycle (How a Vote Travels)

1 Client Submits Vote

Voter clicks option and fires POST /api/polls/:id/vote with fingerprint token. Zero page refresh.

2 O(1) Deduplication

Go handler runs SADD poll:{id}:voters {token}. If returns 0, duplicate is rejected immediately without DB overhead.

3 Atomic Memory Tally

Redis executes HINCRBY poll:{id}:counts {optionId} 1 in single-digit microseconds with zero row-locking deadlocks.

4 Pub/Sub Broadcasting

Tally snapshot published to Redis channel poll:{id}:events, immediately received by all subscribed backend instances.

5 SSE Event Stream

Active viewer streams receive text/event-stream JSON payloads over HTTP/2. React animates results live.

6 Async Audit Persistence

An immutable audit record is asynchronously written to MongoDB Atlas votes collection for durable storage.
